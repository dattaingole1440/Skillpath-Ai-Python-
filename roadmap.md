## Stage 1: How the Web Works

**Duration:** 1 week  
**Prerequisites:** None

### Topics to Learn
- [ ] What is the Internet?
- [ ] How browsers work (rendering engine, JS engine)
- [ ] HTTP / HTTPS protocols & status codes
- [ ] DNS resolution
- [ ] Client-server architecture
